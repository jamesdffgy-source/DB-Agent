# Code of Conduct

DB-Agent welcomes people who want to improve safe, understandable database software.

## Expected behavior

- Discuss code, evidence, and tradeoffs without attacking people.
- Make room for questions from users with different levels of database experience.
- Use synthetic or properly anonymized data in issues, tests, screenshots, and examples.
- Disclose relevant limitations and conflicts of interest.
- Respect maintainers' decisions about security boundaries and release scope.

## Unacceptable behavior

Harassment, threats, discriminatory language, deliberate disruption, exposure of private information, credential sharing, and attempts to bypass responsible security reporting are not accepted in project spaces.

## Enforcement

Maintainers may edit or remove content, lock a conversation, reject a contribution, or temporarily or permanently restrict participation when conduct puts people, data, or the project at risk. Enforcement decisions should be proportional, documented privately where appropriate, and open to reconsideration when new evidence appears.

For ordinary conduct concerns, contact the repository owner through a private GitHub channel. Security vulnerabilities follow [SECURITY.md](SECURITY.md). Do not place private personal or database information in a public report.
